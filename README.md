# DeepSkinDiag-XAI-An-Explainable-Multimodal-AI-System-for-Web-Based-Skin-Disease-Diagnosis
A multimodal AI PWA for skin disease diagnosis integrating EfficientNet (Image) and DistilBERT (Symptom Text) via Late Fusion. Provides transparent decisions using Grad-CAM (XAI) and calibrated confidence scores for safe, bilingual (Sinhala/English) user guidance.
